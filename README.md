# ScheduleTracker
Schedule Tracker  простое и удобное приложение для просмотра расписания. Больше не нужно каждый раз заходить на Яндекс.Диск, выискивать нужный документ и вглядываться в неудобные таблицы Excel все занятия собраны в одном месте в понятном виде.

Что делает проект:

Это простое десктопное приложение для просмотра расписания пар. Оно само заходит на Яндекс.Диск, скачивает свежие Excel-файлы, вытаскивает оттуда расписание нужной группы и показывает его в чистом, понятном интерфейсе.
Почему это удобно

Больше не нужно каждый раз лезть в облако, качать таблицы и щуриться в мелкие ячейки Excel. Приложение само следит за обновлениями и всегда держит актуальное расписание под рукой.

Из приятных мелочей:

• Темная тема, чтобы не резало глаза вечером.

• Офлайн-режим данные сохраняются на компьютер, так что расписание откроется даже без интернета.

• Умное переключение после 20:00 приложение автоматически показывает пары на завтра.

Как начать пользоваться

Никакой сложной установки: просто скачайте готовый .exe файл и запустите его. При первом запуске нужно будет один раз выбрать свою группу из списка. Дальше программа всё сделает сама  при следующих открытиях вы сразу 
увидите свои пары.
